# Panorama de Herramientas para la Ingeniería de Software (Tradicionales vs IA)

Actividad de Software Engineering Models para identificar y comparar herramientas de modelado, control de versiones, gestión, pruebas y asistencia con IA. Incluye 14 fichas breves (7 tradicionales y 7 con IA), con características, aplicabilidad en proyectos reales, licencias, costos, referencias IEEE y declaración de uso de IA.
