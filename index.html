Panorama de Herramientas para la Ingeniería de Software (Tradicionales vs IA)

Comparación de 14 fichas de herramientas para elegir soluciones de desarrollo y modelado según las necesidades de un proyecto.

Objetivos. Identificar y clasificar herramientas actuales de desarrollo y modelado, distinguiendo las tradicionales de las basadas o asistidas por IA. Evaluar sus características, licencias y casos de uso para determinar su aplicabilidad en proyectos reales.

02 / Clasificación

Tradicionales y asistidas por IA

Tradicionales

El usuario define modelos, cambios y pruebas mediante funciones y reglas explícitas. Aportan control, organización y trazabilidad.

Con IA

Generan o refinan propuestas de diagramas, documentación y código a partir de instrucciones. Sus resultados requieren revisión humana.

Clasificación según la función analizada. Visual Paradigm aparece en ambos grupos por sus funciones tradicionales y su chatbot; algunos productos combinan ambos enfoques.

04 / Estructura y control

Herramientas tradicionales

Tipo · Modelado de software

StarUML [1] [2]

Características clave

  • Diagramas UML 2 y entidad-relación.
  • Modelos C4 y soporte de Mermaid.
  • Extensiones para generar código.

Aplicabilidad en proyectos

Diseñar clases, secuencias y componentes en proyectos académicos o aplicaciones pequeñas y medianas.

Pago

USD 129 por dispositivo, pago único para V7 Standard, sin IVA. Licencia propietaria; las funciones avanzadas dependen de la edición.

Tipo · Modelado UML, SysML y BPMN

Visual Paradigm [3] [4]

Características clave

  • Diagramación UML y SysML.
  • Modelado de procesos BPMN.
  • Ingeniería de código según edición.

Aplicabilidad en proyectos

Integrar requisitos, UML y procesos BPMN en proyectos con documentación y colaboración formal.

Freemium

Community: USD 0, solo uso no comercial. Modeler: USD 99 en licencia perpetua individual mostrada en la tienda. Propietaria; Community no incluye todas las funciones citadas.

Tipo · Control de versiones y colaboración

Git / GitHub [5] [6]

Características clave

  • Git registra el historial mediante commits.
  • Git permite ramas y fusiones de cambios.
  • GitHub aloja repositorios remotos.

Aplicabilidad en proyectos

Versionar código y diagramas textuales; revisar cambios de un equipo mediante pull requests.

Gratuito · Git Freemium · GitHub

Git: USD 0, GPL v2. GitHub Free: USD 0; Team anunciado a USD 4 por usuario/mes. GitHub es un servicio propietario; revisar las condiciones de facturación.

Tipo · Gestión de proyectos y tareas

Jira [7] [8]

Características clave

  • Planificación y asignación de tareas.
  • Vistas de tablero, lista y cronograma.
  • Flujos de trabajo configurables.

Aplicabilidad en proyectos

Planificar entregas, asignar responsables y dar seguimiento a requisitos e incidencias del proyecto.

Freemium

Free: USD 0 para hasta 10 usuarios. Servicio propietario. Standard y Premium: Verificar en sitio oficial; el importe depende de usuarios y facturación.

Tipo · Desarrollo y pruebas de API

Postman [9]

Características clave

  • Cliente para enviar solicitudes a API.
  • Organización en colecciones.
  • Ejecución de colecciones y pruebas.

Aplicabilidad en proyectos

Validar contratos y respuestas de API en sistemas web, móviles o de microservicios.

Freemium

Free: USD 0. Solo: USD 9/mes, facturado anualmente. Licencia propietaria; los límites varían por plan.

Tipo · Modelado integrado y gestión de requisitos

Enterprise Architect [22] [23]

Características clave

  • UML, SysML y BPMN según edición.
  • Trazabilidad entre requisitos y diseño.
  • Simulación de modelos de comportamiento.

Aplicabilidad en proyectos

Gestionar proyectos complejos que requieren trazabilidad entre requisitos, diseño, implementación y pruebas.

Pago

Professional: USD 245 por licencia estándar. Propietaria; otras ediciones y licencias flotantes tienen tarifas distintas.

Tipo · Diagramación textual de software

PlantUML [24] [25]

Características clave

  • Clases, secuencias y casos de uso UML.
  • Actividades, estados y componentes.
  • Descripción de diagramas mediante texto.

Aplicabilidad en proyectos

Mantener diagramas UML como texto junto al código, con revisión de cambios mediante Git.

Gratuito

USD 0. Código abierto bajo GPL; existen distribuciones alternativas con otras licencias. Comprobar la distribución utilizada.

05 / Asistencia generativa

Herramientas con IA

Tipo · Asistente de análisis y agente de programación

Claude / Claude Code [14] [15]

Características clave

  • Conversación y creación de Artifacts.
  • Projects para organizar contexto.
  • Análisis y edición de archivos.

Aplicabilidad en proyectos

Analizar requisitos y proponer borradores de modelos textuales; usar Claude Code para cambios en archivos y código bajo revisión.

Freemium

Claude Free: USD 0; Pro: USD 20/mes con facturación mensual. Pro incluye Claude Code sujeto a límites. Servicio propietario; la API tiene facturación distinta.

Tipo · Modelado y diagramación asistidos por IA

Visual Paradigm AI Chatbot [16] [17]

Características clave

  • Generación de diagramas desde texto.
  • Refinamiento mediante conversación.
  • UML, SysML, C4 y BPMN.

Aplicabilidad en proyectos

Convertir requisitos en borradores UML, SysML o BPMN y refinarlos antes de aprobar el diseño.

Pago

VP Online Deluxe: USD 38 por usuario/mes con facturación mensual; USD 30 por usuario/mes con facturación anual. Prueba de evaluación disponible. Función propietaria.

Tipo · Diagramación colaborativa asistida por IA

Lucidchart con Lucid AI [18] [19]

Características clave

  • Generación de diagramas en el lienzo.
  • Refinamiento de propuestas con IA.
  • Resúmenes del contenido visual.

Aplicabilidad en proyectos

Preparar y revisar colaborativamente diagramas de procesos y vistas generales de un sistema.

Freemium

Registro gratuito disponible. Servicio propietario. Precio de planes de pago y límites actuales de IA: Verificar en sitio oficial.

Tipo · Diagramación textual y visual asistida por IA

Mermaid AI (antes Mermaid Chart) [20] [21]

Características clave

  • Diagramas a partir de instrucciones o documentos.
  • Edición de texto Mermaid y vista visual.
  • Clases, secuencias, estados y flujos.

Aplicabilidad en proyectos

Generar y mantener diagramas de clases, secuencias o estados en documentación técnica editable.

Freemium

Inicio gratuito anunciado. Servicio comercial con IA. Tarifas de pago y límites gratuitos: Verificar en sitio oficial.

Tipo · Asistente de código

GitHub Copilot [10]

Características clave

  • Asistencia dentro de editores e IDE.
  • Conversación sobre tareas de código.
  • Modo agente para cambios guiados.

Aplicabilidad en proyectos

Asistir la implementación y revisión de código dentro del IDE, con pruebas antes de integrarlo.

Freemium

Free: USD 0; Pro: USD 10/mes. Servicio propietario. El uso de chat y agentes está sujeto a límites y créditos.

Tipo · Asistente para análisis, diseño y código

ChatGPT [11] [12]

Características clave

  • Interacción mediante lenguaje natural.
  • Razonamiento aplicado a programación.
  • Análisis de archivos con límites por plan.

Aplicabilidad en proyectos

Explorar requisitos y alternativas de diseño, explicar código y proponer modelos textuales para revisión.

Freemium

Free: USD 0; Plus: USD 20/mes, facturación mensual. Servicio propietario. La API se cobra por separado.

Tipo · Editor y agente de programación

Cursor [13]

Características clave

  • Asistencia agéntica para programar.
  • Acceso a Composer.
  • Modelos adicionales según plan.

Aplicabilidad en proyectos

Realizar cambios asistidos en un repositorio y mantener código y documentación técnica bajo supervisión.

Freemium

Hobby: USD 0; Pro: USD 20/mes. Licencia propietaria. Hobby limita las solicitudes al agente; el consumo adicional depende del plan.

06 / Costos y licencias

Comparar acceso y condiciones

Gratuito

Git y PlantUML

Sin costo de licencia. Código abierto; revisar los términos de la distribución utilizada.

Freemium

Acceso básico

Funciones gratuitas y mejoras de pago. Revisar límites de usuarios, proyectos y consumo de IA.

Funciones especializadas

StarUML, Enterprise Architect y VP AI Chatbot. Una prueba de evaluación no equivale a un plan gratuito permanente.

07 / Conclusiones

Elegir según el proyecto

Síntesis de aplicabilidad: selección razonada a partir de las fichas.
NecesidadHerramientas apropiadas
Modelado UML y documentaciónStarUML o PlantUML; Visual Paradigm para un entorno integrado.
Requisitos, procesos y trazabilidadVisual Paradigm o Enterprise Architect, según edición.
Borradores y revisión colaborativa de diagramasVP AI Chatbot, Lucid AI o Mermaid AI; Claude y ChatGPT como apoyo al análisis.
Implementación y entrega en equipoGit/GitHub, Jira y Postman; Copilot o Cursor como asistencia.

Conclusión: combinar herramientas tradicionales para mantener control y trazabilidad con IA para preparar y refinar propuestas. Revisar los resultados: la IA puede omitir requisitos, inventar relaciones o generar código incorrecto.

09 / Transparencia académica

Declaración de Uso de IA Generativa

El presente documento de investigación e informe técnico sobre herramientas de ingeniería de software fue elaborado respetando los principios de transparencia ética y rigor académico.

  1. Búsqueda e investigación de fuentes: Para la recopilación de literatura científica, artículos revisados por pares y análisis comparativos de mercado, se utilizó la plataforma de búsqueda especializada Consensus AI, garantizando el acceso a evidencia empírica procedente de bases de datos académicas internacionales (IEEE, ACM, Elsevier, Springer y MDPI).
  2. Síntesis, resumen y estructuración: La organización sintética del contenido, la estructuración de fichas técnicas y el contraste de datos bibliográficos se llevaron a cabo con el soporte de NotebookLM, utilizando como contexto exclusivo las fuentes científicas cargadas y verificadas.
  3. Validación humana: Todas las fichas técnicas, comparativas de costos, clasificaciones de licenciamiento y referencias bibliográficas fueron revisadas, contrastadas y validadas manualmente por los autores para asegurar la exactitud técnica de los datos entregados.
  4. Desarrollo del recurso visual: Finalmente, se utilizó ChatGPT para desarrollar los archivos HTML y README y elaborar el recurso visual de la presentación. Su trabajo se guio mediante paletas de colores, especificaciones detalladas sobre la información que debía incluirse y otras indicaciones de contenido y diseño.
